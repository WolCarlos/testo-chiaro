# Componenti e licenze di terze parti

Wol Edit Text include componenti open source. I testi delle licenze originali sono distribuiti nella cartella `licenses/` e, per Electron/Chromium, nei file di licenza presenti nella directory dell’applicazione.

| Componente | Licenza / avviso |
| --- | --- |
| Electron | MIT; vedere `LICENSE.electron.txt` nella distribuzione |
| Chromium e componenti correlati | BSD e altre licenze; vedere `LICENSES.chromium.html` |
| DOMPurify | Apache License 2.0 oppure Mozilla Public License 2.0; file `dompurify-LICENSE` e `dompurify-LICENSE-MPL` |
| markdown-it | MIT, Copyright Vitaly Puzrin e Alex Kocharin |
| markdown-it-task-lists | ISC, Copyright Revin Guillen |
| electron-updater | MIT, Copyright Loopline Systems |

Le dipendenze indirette conservano i rispettivi file di copyright e licenza nei pacchetti inclusi nell’applicazione.

Il nome Wol Edit Text e i contenuti del progetto non devono essere interpretati come marchi o componenti dei titolari delle librerie sopra elencate.
