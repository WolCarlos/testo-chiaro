# Informativa privacy di Wol Edit Text

Ultimo aggiornamento: 3 novembre 2026.

## Titolare e contatti

Il progetto Wol Edit Text è distribuito tramite il repository `WolCarlos/testo-chiaro`. Per richieste privacy è possibile aprire una segnalazione tramite GitHub Issues senza inserire documenti o dati personali non necessari.

## Dati trattati dall’app

Wol Edit Text elabora localmente i testi incollati o importati. Non invia documenti a un server del progetto, non richiede account e non integra analytics, pubblicità, profilazione o sistemi di tracciamento.

Le preferenze dell’interfaccia sono conservate localmente tramite `localStorage`. Non vengono eliminate dagli aggiornamenti.

## Aggiornamenti e GitHub

Quando l’app controlla o scarica un aggiornamento, stabilisce una connessione con GitHub Releases. Non trasmette il contenuto dei documenti. Come per ogni connessione web, GitHub può trattare indirizzo IP, data/ora, user agent e dati tecnici della richiesta secondo la propria informativa e il proprio ruolo di fornitore.

Il download e l’installazione degli aggiornamenti avvengono solo dopo conferma dell’utente.

## Immagini remote

Se l’utente sceglie di conservare immagini collegate a indirizzi esterni, il visualizzatore può richiederle al server di origine. Per evitarlo è possibile attivare **Rimuovi immagini** prima della visualizzazione.

## Conservazione e cancellazione

I documenti non vengono salvati automaticamente dall’app. I file esportati restano nei percorsi scelti dall’utente. Le preferenze possono essere ripristinate dal pannello oppure eliminate rimuovendo i dati applicazione di Windows. La cache dei vecchi installer viene ripulita dopo un aggiornamento; i file obsoleti della cache possono essere eliminati dopo sette giorni.

## Diritti e base giuridica

L’app non raccoglie direttamente dati personali dei documenti. Per eventuali richieste tecniche inviate volontariamente tramite GitHub, il trattamento è limitato alla gestione della richiesta e basato sull’interesse legittimo al supporto del progetto o sul consenso dell’utente, secondo il contesto. È possibile chiedere accesso, correzione o cancellazione tramite i canali GitHub indicati.

Questa informativa descrive il comportamento tecnico della versione 1.4.0 e successive modifiche documentate. Non costituisce consulenza legale.
